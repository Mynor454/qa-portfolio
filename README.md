# QA Portfolio — Mynor Estrada

QA Engineer specialising in API testing, test automation and web security. This repository collects runnable samples of how I work, built on public demo APIs and sites (no client or confidential data).

## Projects

### 1. [API Testing with Postman](./01-api-testing-postman/)
A Postman/Newman collection against the Restful-Booker API: authentication, full CRUD on bookings, negative scenarios, access-control checks, schema validation and response-time assertions. CI-ready with Newman.

**Stack:** Postman, Newman, REST

### 2. [Test Automation with Playwright](./02-test-automation-playwright/)
An end-to-end UI suite for the SauceDemo e-commerce site using the Page Object Model: login (positive and negative), cart, full checkout flow and product sorting. Runs on Chromium and Firefox with HTML reports, traces, screenshots and video on failure.

**Stack:** Playwright, JavaScript, Page Object Model

### 3. [Test Design & Bug Reporting](./03-test-design-and-bug-reports/)
Manual test case design and reproducible defect reports for SauceDemo, with severity/priority, evidence and traceability back to the automated tests.

**Stack:** Test case design, defect reporting, Jira/Xray format
